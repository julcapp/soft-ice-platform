## Использование в Codex / при работе с диаграммами
Для проектных схем Soft_ICE использовать профиль `BRAND_PROFILE.md` как локальную проектную спецификацию оформления, а созданные HTML как эталоны. Генерировать автономный HTML + inline SVG с системными шрифтами, без внешних сетевых ресурсов. Состояния и переходы проверять по коду и ТЗ, показывать подтверждённые/предлагаемые узлы раздельно.

Пример запроса:
> Построй диаграмму архитектуры или рабочего процесса по docs/diagram-design/BRAND_PROFILE.md. Используй подходы Diagram Design: editorial SVG, ортогональные связи, 1-2 акцентных узла, одна понятная тема. Сохрани файл в docs/diagram-design/, без CDN и стороннего JS. Не изменяй production.

## Важное о статусе
Это **проектный дизайн-пилот по методике Diagram Design**, а не установка всего стороннего скилла в Codex или Home-Boss. Никакие `npx`-установщики, скрипты из чужого репозитория, Marketplace auto-update и внешние зависимости не запускались. На рабочем ПК не переключена активная ветка; production не менялся.

## Проверка
- Проверены HTML/SVG-теги и нахождение всех прямоугольников внутри `viewBox 1280×720`.
- Проверено отсутствие удалённых HTTP-ресурсов, `script`, `iframe`, `link`, `img` и CSS-импорта (URI `xmlns` SVG — стандартизованное пространство имён, не сетевой запрос).
- На Home-Boss через `git show` извлечены три HTML-файла во временный каталог, проверены наличие SVG, отсутствие внешних тегов; Git рабочей ветки остался без изменений.
- **Не проведены** screenshot review в браузере, полноценные WCAG-аудит и проверка полноценным upstream lint-render; перед production-публикацией они обязательны.

## Этап 2 (после утверждения)
1. Уточнить палитру по фактическим CSS действующих интерфейсов, согласовать с дизайн-системой.
2. Расширить аудит исходного скилла (скрипты импорта/экспорта, зависимости, установки); при необходимости развернуть проектно и зафиксировать commit.
3. Прогнать browser screenshot/layout + проверку подписи связей, затем внедрять диаграммы в документацию/админку только после отдельного одобрения.
