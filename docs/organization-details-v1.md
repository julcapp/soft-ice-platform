# Организации: реквизиты и контакты

Дата: 2026-10-06. Статус: подготовлено к установке на рабочем сервере.

В служебном доступе организация выбирается из базы. Новая организация создаётся отдельным действием. Выбранная организация передаётся в форму нового техника/мастера. Карточку можно редактировать; сохранение требует подтверждения. Контакты руководителя обязательны в форме, существующие записи остаются совместимыми с nullable полями базы.

Поиск ИНН выполняется backend через https://dadata.ru/api/find-party/. Нужен DADATA_API_TOKEN в окружении softice-display-backend-8800.service. Ключ не вводится в браузере. Без ключа доступно ручное заполнение; контакты провайдер может не вернуть. Результат поиска проверяется оператором перед сохранением.

Добавляющая миграция: 20261006000100_organization_contacts. Установщик backend/scripts/install-organization-details.py сверяет хеши четырёх рабочих файлов, создаёт резервную копию PostgreSQL 16 и панели, добавляет поля в существующую серверную Prisma-схему, регенерирует клиент и перезапускает службу. Другие модели текущей схемы сохраняются. При ошибке файлы возвращаются, добавленные поля не удаляются.

Команда владельца сервера:

```bash
sudo python3 /home/julcapp/soft-ice-worktrees/service-access-media-v1/backend/scripts/install-organization-details.py
```

После PASS обновить панель Ctrl+F5. Пока установщик не запущен, прежняя панель остаётся на рабочем сайте.

Проверки: backend 549 passed / 88 skipped; Admin Console 39 passed и production build; Mini App production build. Проверка отдельной PostgreSQL: backend/scripts/run-service-db-acceptance.py.

Серверная приёмка отдельной PostgreSQL 16 пройдена: миграция, сохранение и изменение руководителя/контактов, роли, аппараты, фотографии, завершение, отзыв доступа и аудит. Установщик на рабочей БД ещё не запускался: нужны права root.
