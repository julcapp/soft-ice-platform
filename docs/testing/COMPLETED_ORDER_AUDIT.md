# Проверка завершённого заказа

19.10.2026. Команда `node backend/scripts/audit-completed-order.cjs <UUID заказа>` использует DATABASE_URL из окружения процесса. Не передавать секреты аргументами и не выводить env.

Проверка выполняется в согласованном снимке PostgreSQL RepeatableRead с SET TRANSACTION READ ONLY. Команда не вызывает банк, повторную выдачу, бонусный обработчик или изменение остатков. Код выхода0 — связи согласованы,2 — найдены расхождения,1 — ошибка проверки.

Связи: Order → Payment; Order → MachineDispenseAttempt → InventoryRuntimeReservation → InventoryRuntimeMovement по sourceId=reservationId. CorrelationId резерва и получения может различаться. Проверяются количество выдач, однократность списания TEST клуба, соответствие суммы, статусы и количества ингредиентов, складская принадлежность. Тестовый providerEventId помечается отдельно: серверная симуляция не доказывает физическую выдачу.

Отсутствие сообщения PURCHASE_COMPLETED отмечается предупреждением; оно не создаётся автоматически и не означает доставку в мессенджер. Сверка не проверяет чеки, комиссию или фактическую массу дозирования.

Проверки: `node --test backend/tests/completedOrderAudit.test.js`. Проверяются корректная связь при разных correlationId, двойные движения/дебиты, неподтверждённый платёж, несовпадение склада и некорректный UUID.
