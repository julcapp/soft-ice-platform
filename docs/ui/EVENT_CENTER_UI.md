# UI Центра событий

Основной раздел Admin Console называется «Центр событий». Список показывает время, важность, категорию, заголовок, субъект, источник, processing state, подтверждение и количество материалов. Доступны период, поиск, категория, важность и статус; foundation-представления охватывают внимание, критические, инциденты, бизнес, связь, видео, обслуживание и платежи.

Карточка показывает нормализованные сведения, correlation chain, evidence, комментарии, теги и разрешённые технические данные. Действия: подтвердить, взять в работу, решить и управлять legal hold.

`EventFeed` поддерживает компактный/полный режим, группировку по дате/корреляции и состояния empty/loading/error/forbidden/stale. Он применяется в карточке автомата и Customer 360. Все пользовательские тексты русские; enum переводятся до отображения.
