# Интерфейс видеонаблюдения

В карточке цифрового двойника добавлена вкладка «Камера и видеонаблюдение». Она показывает установку и статус камеры, модель, расположение, режим, PIR, последнее движение/кадр/проверку, локальный архив, накопитель, срок 72 часа, инциденты и записи.

Действия: «Проверить камеру», «Открыть прямой эфир», «Начать контрольную запись», «Создать инцидент», «Сохранить фрагмент», «Продлить хранение». Прямой эфир заблокирован до media proxy и никогда не получает RTSP URL.

Состояния: загрузка; пусто; устаревшие данные; камера/сервер недоступны; доступ запрещён; `FOUNDATION_ONLY`. Критерии здоровья показываются по отдельности. Интерфейс адаптивен для мобильного, планшета, desktop и больших сенсорных экранов.
