# Интерфейс передачи подарка

На предоплаченном заказе основной CTA остаётся «Показать активный код». Ниже расположены пояснение «Не можете забрать заказ?» и вторичная кнопка «Отказаться или подарить заказ». Выбор и подтверждение открываются последовательно, чтобы не создавать равнозначные CTA.

Форма использует маску `+7 (XXX) XXX-XX-XX`, показывает маскированный телефон, состав, автомат, адрес и срок. Успешный текст: «Подарок отправлен. Мы уведомим получателя через доступные каналы.» Он не утверждает доставку.

Раздел «Мои подарки» показывает отправителя, состав, автомат, адрес, срок и русский статус. CTA последовательно меняются: «Посмотреть подарок», «Принять подарок», «Получить подарок у аппарата», «Показать активный код». Постоянный код после открытия не раскрывается.
