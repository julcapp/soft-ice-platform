# Интерфейс контура управления автоматами

В Консоль администратора добавлены разделы «Автоматы / Контур управления автоматами», детальное состояние автомата, а также «Платформа / Журнал событий» и «Хранилище событий». Представления показывают состояние, активный сеанс, его тип и длительность, историю переходов и сигналов, корреляцию и связанные идентификаторы заказа, платежа и теста, неизменяемые конверты, ошибки доставки, режим данных и актуальность.

Предусмотрены состояния загрузки, отсутствия данных, устаревшей или базовой реализации, недоступности и запрета доступа. Кнопок перехода состояния, повторной попытки, воспроизведения и дистанционного управления нет.
