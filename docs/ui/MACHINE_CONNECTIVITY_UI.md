# Интерфейс связи автомата

В карточке и цифровом двойнике используется блок «Связь и SIM-карта»: оператор, маскированный телефон, тариф, статус, баланс, дата списания, трафик, автопополнение, порог, источник и актуальность.

Предупреждения: низкий баланс, приостановка/блокировка, скорое списание, мало трафика, устаревание и недоступность интеграции.
