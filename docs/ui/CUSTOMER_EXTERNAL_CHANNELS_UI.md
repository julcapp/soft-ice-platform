# Интерфейс внешних каналов

В Customer 360 расположен русскоязычный блок «Внешние каналы» для VK, Telegram, MAX, Email, телефона и Push. Он показывает профиль, подтверждение, подписки, источник, актуальность, связанные согласия и отдельные предупреждения для ручных данных и недоступной интеграции.

Блок «Индекс вовлечённости» показывает балл, уровень, объяснимые факторы, полноту данных, дату расчёта и версию модели.
