Дата: 2026-10-30. Проверка без изменения данных.

- Боевой CRMRuntime.manageAccount вызывает CRMService.manageAccount; метод отсутствует в проверенном боевом CRMService.
- В проверенном боевом CRMService также отсутствуют adjustBonus и eraseAndReleaseCustomer; в локальной версии эти два метода имеются, но не manageAccount. Требуется сверка релизов.
- UI-кнопки не считать рабочими до интеграционных тестов на изолированном клиенте.
- Источник: /home/julcapp/soft-ice-worktrees/display-product-v1/backend. Действующий API 127.0.0.1:8800.
- Нельзя просто заменить CRMService локальным файлом: риск утраты изменений релиза.
- Требуются отдельные операции: изменение имени/почты/телефона с верификацией; блокировка/разблокировка с причиной и сроком; удаление с сохранением обязательных платёжных документов и истории; коррекция бонусов только журналируемой транзакцией.
- Перед публикацией: backup -> diff -> миграции при необходимости -> unit/integration tests -> staging -> deployment -> smoke/rollback.
