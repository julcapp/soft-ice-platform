# Дополнение: отказ и подарок предоплаченного заказа

Оплаченный невыданный заказ может быть закрыт как `CANCELLED_BY_CUSTOMER` с отдельным возвратом на внутренний баланс либо сохранить финансовую принадлежность и передать право получения через `gift_transfer`. Исходная платёжная транзакция не изменяется.
