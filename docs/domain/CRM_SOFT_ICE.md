# Домен CRM Soft ICE

Статус: реализована базовая версия  
Версия: 1.0

## Назначение

CRM Soft ICE — отдельный ограниченный контекст для рабочего места сотрудников, развивающих отношения с клиентами и программу лояльности «Клуб у Тимоши».

## Возможности

- список и поиск клиентов;
- карточка клиента и служебная заметка;
- просмотр клубного и бонусного счетов;
- история пополнений, списаний, покупок и бонусных начислений;
- просмотр реферальной истории;
- просмотр и назначение сегментов через Segmentation Runtime;
- создание акций и кампаний;
- постановка уведомлений в очередь с учётом запрета коммуникаций;
- сводные показатели CRM.

## Владение данными

| Данные | Владелец | Доступ CRM |
|---|---|---|
| Личность клиента | Customer Identity | Проекция только для чтения |
| Согласия | Consent Privacy | Проверка перед коммуникацией |
| Клубный счёт и проводки | Club Account | Чтение и команды через Runtime |
| Бонусный счёт и начисления | Loyalty | Проекция только для чтения |
| Покупки | Orders | Проекция только для чтения |
| Рефералы | Referral/Loyalty | Проекция только для чтения |
| Сегменты | Segmentation | Чтение и команды через Runtime |
| Служебная карточка, кампании, очередь уведомлений | CRM Soft ICE | Полное владение |

## Интеграции

CRM совместима с Admin Console как встроенное рабочее место. Digital Twin, Runtime, Inventory и Maintenance могут передавать обезличенные события для будущей сегментации, но CRM не меняет их состояние. Operator Workspace не получает маркетинговые или финансовые права.

## API

Базовый путь: `/api/v1/admin/crm`.

- `GET /dashboard` — сводка;
- `GET /customers` — клиенты;
- `GET /customers/{customerId}` — карточка;
- `PATCH /customers/{customerId}` — служебные поля;
- `POST /customers/{customerId}/top-ups` — пополнение через Club Account Runtime;
- `POST /customers/{customerId}/segments/{segmentId}` — назначение сегмента;
- `POST /customers/{customerId}/notifications` — очередь уведомлений;
- `POST /campaigns` — создание акции.

Все изменяющие запросы требуют администратора, `Idempotency-Key`, корреляции и аудита. Интерфейс и ответы, предназначенные для человека, формулируются по-русски.
# Foundation-показатели подарков

Карточка клиента может показывать количество отправленных и принятых подарков, активированных gift-referrals, первых собственных покупок и конверсии Gift → Registration / Gift → First Purchase. Сложный BI не входит в v1.
