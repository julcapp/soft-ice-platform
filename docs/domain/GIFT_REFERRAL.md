# Реферальный сценарий подарка

Источник привлечения: `referralSource = GIFT_TRANSFER`. Стадии: `INVITED`, `REGISTERED`, `GIFT_ACCEPTED`, `GIFT_REDEEMED`, `FIRST_OWN_PURCHASE`.

Ввод телефона не считается успешным рефералом. Подаренный товар не является собственной покупкой и не даёт стандартных purchase-бонусов ни отправителю, ни получателю. Коммерческая конверсия наступает только после первой самостоятельной оплачиваемой покупки приглашённого клиента. Размер и правила награды принадлежат Referral/Loyalty, а `gift_transfer` публикует факты через адаптер и общий Event Bus.
