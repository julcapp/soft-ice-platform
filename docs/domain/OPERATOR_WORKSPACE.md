# Рабочее место оператора v1

Статус: реализовано  
Дата: 2026-07-24

## Назначение

Рабочее место оператора — русскоязычный прикладной вертикальный срез для ежедневного обслуживания автоматов. Оно не становится новым владельцем машинного, складского или ремонтного состояния, а объединяет команды существующих контуров в один безопасный сценарий.

## Возможности v1

- список автоматов, назначенных текущему оператору;
- карточка автомата с адресом, состоянием, комплектацией и остатками;
- сессия обслуживания с обязательным чек-листом;
- обязательная фотофиксация этапов «до» и «после»;
- тест выдачи стаканчика и мороженого;
- тест сиропов только для автоматов с сиропными линиями;
- списание материалов обслуживания;
- отдельная классификация тестовых расходов `TEST_CONSUMPTION` с признаком `commercialSale: false`;
- неизменяемый после завершения журнал действий;
- публикация событий Runtime и агрегат для Digital Twin;
- область доступа оператора ограничена назначенными ему автоматами и собственными сессиями.

## Границы ответственности

`OperatorWorkspace` отвечает за пользовательский сценарий и его прогресс. `Maintenance Runtime` остаётся владельцем жизненного цикла обслуживания, `Inventory Runtime` — складских движений, `Machine Runtime` — исполняемого состояния, а `Machine Digital Twin` — проекцией только для чтения. Бинарные фотографии должны храниться в объектном хранилище; v1 принимает проверяемые метаданные, ключ и SHA-256.

## События

- `OperatorWorkspace.SessionOpened`;
- `OperatorWorkspace.ChecklistUpdated`;
- `OperatorWorkspace.PhotoAttached`;
- `OperatorWorkspace.TestPerformed`;
- `OperatorWorkspace.ConsumableWrittenOff`;
- `OperatorWorkspace.SessionCompleted`.

Все изменяющие команды требуют `Idempotency-Key`, идентификатор оператора и роль. События несут `correlationId`, оператора, автомат и сессию.

## Ограничения v1

Активный репозиторий рабочего места хранится в памяти процесса и содержит демонстрационные назначения. Для промышленной эксплуатации нужны PostgreSQL-адаптер, доверенная аутентификация оператора, объектное хранилище фотографий, транзакционный outbox и аппаратный адаптер тестовых команд.
