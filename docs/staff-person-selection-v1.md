# Сотрудники: выбор и совмещение ролей

Дата: 2026-10-06. Статус: подготовлено к установке.

Одна карточка сотрудника может быть выбрана для логинов техника и мастера. Существующая карточка выбирается из базы; недостающая служебная роль назначается после подтверждения с аудитом. Формы создания учитывают организацию, существующую карточку и новую карточку отдельно. Одноимённые люди автоматически не объединяются.

Действующие роли сотрудника и роль конкретного логина проверяются независимо. Старые назначения аппаратов сохраняются; право на аппарат нужно назначить каждой роли. Пароль существующего логина при привязке не меняется.

PasswordInput используется для входа, нового сотрудника и смены пароля. Глазок меняет видимость, сохраняет значение и не отправляет форму. Минимум 9 символов сохранён.

Новые и изменяемые ФИО нормализуются на сервере и при выходе из поля в форме: заглавная первая буква каждого слова/части двойной фамилии, нормализация пробелов. spellCheck и lang=ru включают доступную проверку браузера, но проверка фамилий словарём не гарантируется и имена автоматически не заменяются. Существующие записи массово не переименовываются.

Проверки: backend 550 passed / 88 skipped; Admin Console 42 passed, сборки Admin Console и Mini App прошли.

Обновление не меняет структуру БД. Установщик сверяет рабочие файлы, сохраняет копию файлов backend и панели, перезапускает службу и проверяет закрытость маршрута. При ошибке возвращает файлы. Команда владельца сервера:

```bash
sudo python3 /home/julcapp/soft-ice-worktrees/service-access-media-v1/backend/scripts/install-staff-person-selection.py
```

После PASS обновить панель Ctrl+F5. Для логина техника выбрать сотрудника мастера в выпадающем списке и подтвердить связь/роль.

Серверная приёмка PostgreSQL 16 PASS: один человек с двумя служебными ролями, отсутствие дубликата карточки/активной роли, запрет выбора сотрудника другой организации, сохранение пароля, нормализация ФИО и раздельные права логинов. Рабочая база использована только для чтения структуры.
