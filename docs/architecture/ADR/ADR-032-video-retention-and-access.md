# ADR-032 — Хранение видео и доступ

Дата: 2026-07-24  
Статус: Accepted

Стандартный срок хранения видео — 72 часа, затем данные автоматически удаляются после достижения цели. `legalHold` является отдельным привилегированным решением: только `PLATFORM_OWNER` либо `ADMIN` с `video:legal_hold`. Любое продление, hold/release, просмотр, выгрузка и удаление аудируются.

Секреты подключения находятся вне прикладной БД, API маскирует технические адреса и secret references. Публичные ссылки запрещены; браузер использует будущий media proxy. Архив доступен `PLATFORM_OWNER`, `ADMIN`, `SECURITY_OFFICER`; оператор не получает его по умолчанию.
