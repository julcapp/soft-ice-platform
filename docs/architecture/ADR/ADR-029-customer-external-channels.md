# ADR-029 — Универсальные внешние каналы Customer 360

Статус: принято. Дата: 2026-07-24.

Customer 360 хранит агрегированные внешние профили и подписки отдельно от коммуникационных разрешений. Consent Core остаётся источником юридической истины. Официальный внешний сервис является источником фактической подписки, ручной источник не получает статус внешней проверки. VK реализован через ручной и mock-адаптеры; официальный API заблокирован до получения документации и реквизитов.
