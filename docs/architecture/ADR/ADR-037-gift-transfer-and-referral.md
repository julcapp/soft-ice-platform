# ADR-037: Передача права получения и реферальная связь

Статус: Принято  
Дата: 2026-08-14

Решение: выделить `gift_transfer` в bounded context. Он не переносит платёж и не создаёт заказ или fulfillment flow, а назначает право получения существующего заказа. Финансовые возвраты проходят отдельной записью Club Account ledger; исходный платёж неизменяем. Referral/Loyalty получает стадии через контракт и самостоятельно определяет награды.

Следствия: одна активная/историческая передача на заказ; подтверждённый телефон обязателен; invitation token хранится как hash; выдача одноразовая; стандартные бонусы за подарок запрещены. Runtime v1 — `FOUNDATION_ONLY` до durable repository и транзакционного outbox.
