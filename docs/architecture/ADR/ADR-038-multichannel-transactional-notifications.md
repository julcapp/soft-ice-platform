# ADR-038: Равноправные транзакционные каналы

Статус: Принято  
Дата: 2026-08-14

Решение: одна Notification оркестрируется во все разрешённые каналы. Telegram и MAX равноправны, каждому соответствует отдельная попытка доставки; подарок и бизнес-событие остаются единственными. Provider confirmation не моделируется без фактического API-сигнала.

Следствия: частичный успех допустим; статусы каналов независимы; MAX production имеет `BLOCKED_EXTERNAL`; второй Telegram Bot и второй Event Bus не создаются.
