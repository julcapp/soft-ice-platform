# ADR-031 — Событийная видеозапись

Дата: 2026-07-24  
Статус: Accepted

Видеонаблюдение является отдельным bounded context. Оно подписывается на Platform Event Bus и сопоставляет подтверждённое движение/события автомата с записью. PIR только будит камеру; камера подтверждает движение в зоне. Активная сессия продлевается вместо создания коротких файлов, применяется pre/post buffer и верхний предел длительности.

V1 использует mock/in-memory adapters. Реальные RTSP, NVR, FFmpeg, S3-compatible storage и edge-agent требуют внешних решений (`BLOCKED_EXTERNAL`). Лицевые и биометрические функции запрещены.
