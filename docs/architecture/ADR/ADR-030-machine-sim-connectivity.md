# ADR-030 — SIM-карта и мобильная связь автомата

Статус: принято. Дата: 2026-07-24.

Machine Domain владеет SIM-картой и тарифом; Digital Twin публикует только read-only проекцию. Ручные и операторские данные не смешиваются. Реальные операторские адаптеры заблокированы до официальных контрактов и реквизитов. Оператор рабочего места не изменяет SIM, тариф и баланс.
