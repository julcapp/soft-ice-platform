# Домены и контуры интерфейсов

Все зарегистрированные имена направлены на IP `78.140.15.84`.

| Домен | Назначение | Кодовая база |
|---|---|---|
| `utimoshi.ru` | Публичный сайт | Web frontend |
| `app.utimoshi.ru` | Mini App | Mini App frontend |
| `display.utimoshi.ru` | Терминал/монитор аппарата | Terminal frontend |
| `admin.utimoshi.ru` | Административная панель | Admin Console |
| `tehnik.utimoshi.ru` | Панель технического специалиста | Admin Console + роль TECHNICIAN |
| `master.utimoshi.ru` | Панель мастера | Admin Console + роль MASTER |

## Архитектурное решение

`admin`, `tehnik` и `master` используют одну кодовую базу Admin Console. Доступные разделы определяются серверными ролями и разрешениями, а не отдельными копиями проекта.

`display` является отдельным интерфейсом терминала с отдельной аутентификацией устройства.

## Текущее состояние

- DNS зарегистрирован.
- Nginx-конфигурации ещё не утверждены.
- TLS-сертификаты должны настраиваться перед вводом интерфейсов в эксплуатацию.
- Эти домены нельзя направлять на незавершённые feature-ветки.

## Проверка производительности Mini App

Целевые показатели:

- первый skeleton: не более 1 секунды;
- API TTFB p75: не более 500 мс;
- холодная загрузка MAX p75: не более 3 секунд, p95: не более 5 секунд;
- тёплая загрузка p75: не более 1,5 секунды;
- профиль и баланс p75: не более 800 мс;
- ответ бота p75: не более 1 секунды, p95: не более 2 секунд;
- начальный JavaScript желательно не более 150 КБ gzip.

Telegram, MAX и обычный браузер проверяются отдельно. Изменение требований допускается только после фактических измерений.
