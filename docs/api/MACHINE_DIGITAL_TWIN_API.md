# API цифрового двойника автомата, версия 1

Статус: реализована базовая версия только для чтения  
Базовый маршрут: `/api/v1/admin/machine-twins`

## Авторизация

Роли `PLATFORM_OWNER` и `ADMIN` могут читать данные. Роли `REGIONAL_MANAGER`, `SUPPORT` и
`READ_ONLY_AUDITOR` зарезервированы для будущих политик с ограниченной областью. Роли `OPERATOR`
доступ запрещён; будущее рабочее место оператора должно использовать отдельную область назначенных автоматов.

## Маршруты

- `GET /` — список проекций.
- `GET /:machineId` — детальная проекция.
- `GET /:machineId/components` — проекции компонентов.
- `GET /:machineId/events` — неизменяемые нормализованные события двойника.
- `GET /:machineId/snapshots` — неизменяемые снимки.
- `GET /:machineId/health` — объяснимое общее состояние и состояние компонентов.

Ответы используют структуру `{ data, meta }`; значение `meta.access` равно `READ_ONLY`.
Маршрутов `POST`, `PUT`, `PATCH` и `DELETE` нет.

Демонстрационные записи содержат `dataMode: DEMO`, `generatedAt` и `source`.
Доступность источника указывается явно и не означает, что он является источником истины.
