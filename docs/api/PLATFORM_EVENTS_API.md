# API журнала событий для администратора, версия 1

Роли `PLATFORM_OWNER` и `ADMIN` могут читать:

- `GET /api/v1/admin/platform-events`
- `GET /api/v1/admin/platform-events/:eventId`
- `GET /api/v1/admin/platform-events/dead-letter`

Запросы списка можно фильтровать по `eventType` и `aggregateId`. Детальный ответ содержит попытки и статус доставки. Метаданные явно указывают синхронную доставку внутри процесса и непостоянное хранение в памяти. В версии 1 нет API для повторного воспроизведения, публикации, повторной доставки, удаления или изменения данных.
