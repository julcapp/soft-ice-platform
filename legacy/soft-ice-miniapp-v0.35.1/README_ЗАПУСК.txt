1. ЛОКАЛЬНАЯ ПРОВЕРКА БЕЗ TELEGRAM

1. Полностью распакуйте ZIP-архив в отдельную папку.
2. Дважды щёлкните START_SOFT_ICE.bat.
3. Откроется Mini App с пометкой «Локальный демонстрационный профиль».

Адреса:

- Mini App: http://localhost:8780/
- терминал аппарата: http://localhost:8780/index.html
- склад: http://localhost:8780/warehouse.html
- операции и журнал: http://localhost:8780/operations.html

Локальный профиль: Александр, @soft_ice_demo, баланс 187 бонусов.

2. ПОДКЛЮЧЕНИЕ НАСТОЯЩЕГО TELEGRAM-БОТА

Потребуются:

- Python 3;
- бот, созданный в @BotFather командой /newbot;
- токен этого бота;
- публичный HTTPS-адрес Mini App: https://app.utimoshi.ru/.

Важно: Telegram не открывает Mini App по localhost. Домен app.utimoshi.ru должен
через HTTPS-прокси передавать запросы работающему серверу Soft_ICE. Корень /
автоматически открывает tma.html.

Запуск:

1. Дважды щёлкните START_TELEGRAM_BOT.bat.
2. Введите НОВЫЙ токен BotFather. Ввод скрыт; токен не сохраняется в файлах.
3. Подтвердите готовый адрес https://app.utimoshi.ru/ клавишей Enter.
4. Откройте созданного бота в Telegram и отправьте /start.
5. Нажмите «Открыть У Тимоши».

При запуске сервер сам проверяет бота и настраивает кнопку меню. Команды /start
и /menu отправляют кнопку запуска Mini App. Если токен принадлежит не
@desserty_bot, бот не запускается.

Ранее опубликованный в переписке токен использовать нельзя. Отзовите его в
@BotFather командой /revoke и используйте только заново выпущенный токен.

3. КАК РАБОТАЕТ АВТОРИЗАЦИЯ

Mini App передаёт серверу исходную строку initData. Сервер:

- пересчитывает подпись с использованием токена бота;
- сравнивает подписи безопасным способом;
- проверяет время создания сессии;
- извлекает Telegram user ID только после успешной проверки;
- создаёт или обновляет профиль клиента;
- связывает новые предзаказы с этим профилем.

Данным Telegram.WebApp.initDataUnsafe сервер не доверяет. Токен бота никогда не
передаётся в браузер и не входит в ZIP-архив.

4. ПРЕДЗАКАЗ И ПОЛУЧЕНИЕ

1. Пользователь открывает Mini App из Telegram.
2. Сервер подтверждает его Telegram-профиль.
3. Пользователь выбирает аппарат, топпинг и добавку.
4. После демонстрационной оплаты получает QR-код и шестизначный код.
5. На терминале заказ выдаётся один раз через Machine Gateway.

Сохраняются правила v0.27:

- срок получения — 48 часов;
- QR обновляется каждые 5 минут;
- код выдаётся только один раз;
- три ошибки включают паузу 60 секунд, но не аннулируют заказ;
- предзаказ привязан к выбранному аппарату;
- бонусы за предоплату пока не начисляются;
- истёкшая предоплата направляется на клубный счёт.

5. ПРОВЕРКА СМЕНЫ ВКУСА

1. Откройте склад и в разделе «Смесь в аппарате» выберите «Банан».
2. Нажмите «Применить новый вкус».
3. Обновите терминал или Mini App — в карточке продукта появится банановое мороженое.
4. После успешной выдачи остаток банановой смеси уменьшится на одну порцию.

6. ОГРАНИЧЕНИЯ v0.30

- ЮKassa, онлайн-касса и реальный контроллер аппарата ещё не подключены;
- оплата и QR-изображение остаются демонстрационными;
- для рабочего Telegram-запуска нужен внешний HTTPS-адрес;
- PowerShell-резервный сервер поддерживает только локальный деморежим;
- связь Telegram-профиля с ранее зарегистрированным номером телефона будет
  отдельным следующим этапом и потребует подтверждения владельца номера.

Чтобы вернуть исходную тестовую базу, остановите сервер и удалите
crm_test_data.json рядом с программой.
