# Этапы TimoPOS — 17 ноября 2026

## Подтверждённый результат в ветке

- Подготовлен автономный кассовый прототип v0.9; отдельная локальная тестовая копия запускалась на ПК TimoPOS.
- Сервисный вход: три быстрых нажатия на номер терминала открывают **только форму входа**, не дают права техника.
- Подготовлена политика ролей TECHNICIAN / MASTER / PLATFORM_ADMIN с привязкой сотрудника и сессии к точке и терминалу, ограничением операций и дополнительным подтверждением опасных команд.
- Подготовлен opt-in HTTP API MAX-кодов продавца: запрос, проверка, сессия, выход. Не активирован в production.
- Добавлены адаптер MAX-бота и фабрика зависимостей с AES-GCM для адресата, исправлено сопоставление организационной роли OPERATOR.
- Изолированный набор из **63 выбранных тестов прошёл (63/63)** в последнем зафиксированном прогоне; полноценный набор интеграционных испытаний не проводился.

Коммиты этапа: `d5fcbf4`, `413d560`, `71a5881`.  
Подробная проверка: [docs/timopos/SERVICE_ACCESS_CHECKPOINT_20261117.md](../../docs/timopos/SERVICE_ACCESS_CHECKPOINT_20261117.md).

## Не завершено

- Настройка и испытание PostgreSQL на отдельной БД, проверка миграций и согласованной схемы MAX-привязки
- Живые запросы к тестовому MAX-боту, защищённый ограничитель попыток, журнал входов
- Полная авторизация техника / мастера через реальные серверные сессии и API
- Интеграция смен, заказов, ККТ и **тестовых**, а не рабочих, платежей
- Испытания сканера, принтера, кофемашины и иных устройств
- Поддерживаемая платформа для самостоятельного приложения и сборка EXE

**Граница безопасности:** в указанных коммитах production, реальная оплата и оборудование не включались.
