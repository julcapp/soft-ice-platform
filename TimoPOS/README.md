# TimoPOS — терминал продавца «У Тимоши»

**Модуль:** кассовое рабочее место продавца. **Домен:** [timopos.utimoshi.ru](https://timopos.utimoshi.ru/).  
**Статус:** разработки и проверки в изолированной ветке; публикация на рабочий домен только после согласованной приёмки.

Эта папка — официальный **каталог TimoPOS внутри монорепозитория**: этапы, решения, точки входа в исходники и результаты проверок. Исполняемый код пока остаётся в существующих путях, чтобы не сломать импорты и сборку. Не хранить здесь копии секретов, ключей, токенов MAX, реквизитов оплаты или персональных данных.

## Правила работ

1. Каждому этапу — дата, отдельный коммит, результаты проверок, известные ограничения.
2. Рабочие платежи, ККТ, выдача товара, production PostgreSQL — без несанкционированных изменений.
3. Тестовая оплата и демонстрационные квитанции не равны успешной реальной оплате или фискализации.
4. Общие сервисы CRM, каталога и платёжного ядра остаются общими, не копируются внутрь TimoPOS.
