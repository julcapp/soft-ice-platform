## Правила

Номер торговой точки отличается от ID терминала. Администратор назначает сотруднику роль OPERATOR и точку; MAX подтверждает личность; backend проверяет полномочия и срок действия сессии на каждом запросе. Тройное нажатие **только** открывает сервисную форму. Реальные кассовые операции требуют подтверждённого платежа, открытой смены, работающей ККТ и запрета повторной выдачи. Секреты никогда не хранить в репозитории.
