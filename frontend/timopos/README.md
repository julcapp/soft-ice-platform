# TimoPOS 2.0 — интерфейс продавца

Адрес назначения: https://timopos.utimoshi.ru (основной сервер 78.140.15.84).

**Важно:** этот каталог пока содержит только изолированный HTML-прототип. Он не подключен к API, оплате, заказам или физической выдаче. На production не развёрнут.

## Интерфейс, этап 1
- Цветовая палитра из display: cream #fff9ef, coral #ff5c63, green #118d74, ink #241b16.
- Верхняя панель: точка, локальные часы браузера, будущие локация и погода, статус режима.
- Плитки: Продажа, Получить, Заказы, Клиенты, Смена, Остатки, Журнал, Настройки.
- На плитке **Получить**: ввод шести цифр и место под QR-камеру; реального погашения нет.
- Адаптивность планшет/ПК/смартфон. Нет секретов в браузере.

## Этап 2 — только после ревизии сервера и API
1. Авторизация продавца, роль и открытая смена, точка №001.
2. Актуальные цены и ассортимент с backend, не хардкодить коммерческие значения.
3. API ручной выдачи для Mini App/сайта: проверка Payment SUCCEEDED, владельца/точки, TTL, возврата, состояния заказа; атомарное бронирование и подтверждение фактической выдачи.
4. Защита от повторных запросов и параллельной выдачи; журнал (actor, point, shift, event, order, timestamp).
5. Сканирование QR и ручной ввод, доступность и ошибочные сценарии.
6. Интеграционные и E2E тесты, staging, согласованный релиз и rollback.

Исходный код готовится в отдельной ветке, без изменений main и production. Связанная задача: #31.
