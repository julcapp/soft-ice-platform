# Состояние проекта «У Тимоши»

Обновлено: 08.09.2026

## Источник истины

- Репозиторий: `julcapp/soft-ice-platform`.
- Стабильная ветка: `main`.
- Единая интеграционная ветка следующего релиза: `integration/unified-v0.36.0`.
- GitHub является единственным источником истины для исходного кода и истории изменений.
- Сервер используется для проверки и развёртывания, но не для прямого редактирования исходников.

## Состояние интеграции

В интеграционной ветке собраны и последовательно проверяются:

- Bot Core для Telegram и MAX;
- безопасное принятие и доставка подарков;
- Promotion и Pricing Engine;
- Photo Verification Agent;
- Equipment Integration Sandbox;
- PostgreSQL runtime-контуры Gift Transfer, Sale Flow, Inventory и Transactional Outbox;
- Admin Console и производственный снимок Mini App в `legacy/`.

Последний завершённый increment: безопасная доставка приглашений о подарке через
проверенные и зашифрованные Telegram/MAX bindings. Канальные флаги выключены.

## Продакшен

- Последние integration-инкременты не развёрнуты.
- Версию, рабочий каталог, состояние миграций и резервной копии необходимо повторно проверять непосредственно перед релизом.
- Запрещено включать Telegram/MAX delivery flags до тестовой миграции, настройки ключа шифрования и канальной приёмки.

## Ближайшие задачи

1. Завершить надёжную очередь Telegram/MAX уведомлений через Transactional Outbox.
2. Проверить миграции на отдельной тестовой PostgreSQL.
3. Выполнить приёмку тестовых Telegram и MAX ботов без production-токенов.
4. Провести ревизию интерфейсов и единой ролевой Admin Console.
5. Подготовить релиз `v0.36.0` только после полной приёмки и отдельного решения о развёртывании.

## Ограничения безопасности

- Не хранить токены, пароли, ключи шифрования и реальные идентификаторы получателей в Git.
- Не использовать production-базу для интеграционных тестов.
- Не считать приглашение отправленным до подтверждённого provider-вызова.
- Перед объединением обязательны тесты, сборка, проверка миграций и отсутствие конфликтов.
