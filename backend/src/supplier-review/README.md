# Кабинет поставщика v1

Отдельное справочное представление на `/api/supplier-review/` для проверки интеграции поставщиком. Русский, английский и упрощённый китайский интерфейс. Это не полный перевод рабочей админ-панели. Все характеристики помечены как сведения поставщика; неподтверждённые параметры явно обозначены. Данные покупателей, платежи и команды оборудования отсутствуют.

## Доступ

Изолированная учётная запись не создаёт AdminSession и не предоставляет административную роль. Пароль хранится как scrypt-хеш с солью в конфигурации вне репозитория. Cookie HttpOnly/Secure/SameSite=Strict, срок сессии до 8 часов. На каждом защищённом запросе проверяются enabled, expiresAt и version. Срок доступа — один календарный месяц с 15.10.2026 по 15.11.2026, 13:47:11 по Томску. Смена срока или отзыв аннулируют ранее выданные сессии. 8 неудачных входов блокируют новые попытки на 15 минут в пределах процесса. Перезапуск сбрасывает счётчик попыток.

## Управление на сервере

Запускать от владельца сервиса, путь к конфигурации по умолчанию задан в manage.cjs.

- `node src/supplier-review/manage.cjs status` — срок и состояние без секретов.
- `node src/supplier-review/manage.cjs extend 2026-12-15T06:47:11Z` — пример продления; выполнять только по решению владельца платформы.
- `node src/supplier-review/manage.cjs revoke` — немедленно отозвать доступ.

Автоматического продления нет. Существующие сессии основного кабинета не изменяются. Для входа после продления требуется повторная авторизация.

## Проверки

`node --test src/supplier-review/router.test.js`: вход, cookie, отказ без авторизации, срок, подмена cookie, отзыв, запрет команд и ограничение попыток. Проверить браузером три языка и мобильную ширину, отсутствие ошибок JS. После публикации проверить основной /health и отказ основного admin API с cookie поставщика.
