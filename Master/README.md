# Master — сервисный интерфейс мастера Soft_ICE

**Точка входа:** `master.utimoshi.ru`.  
**Принцип:** отдельная документация и этапы, но не отдельный клон Admin Console.

## Каноническая архитектура

Согласно [ADR-050](../docs/architecture/ADR/ADR-050-unified-admin-console-entrypoints.md), три адреса администратора, техника и мастера используют **один frontend** `AdminDesktop/app/`. Поддомен выбирает UX-профиль, но **не выдаёт полномочий**.

ADR-050 закрепляет серверную роль `MACHINE_RESPONSIBLE` для ответственного за аппарат с ограничением по назначенным устройствам. Эта роль не означает автоматического доступа ко всем операциям калибровки или изменению платежей.

## Работы и ограничения

- [Журнал этапов](stages/2026-11-17.md)
- Диагностика, ремонт, калибровка, обслуживание и управление аппаратом требуют проверки полномочий, устройства, сессии и журналирования на backend
- Сервисное меню терминала TimoPOS не должно обходить серверный контроль
- Согласовать новую сервисную политику TimoPOS с ADR-050 **до** включения настоящих сервисных API
